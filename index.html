Share what you have with the people next door.

Your street already has the ladder, the mower and the folding tables it needs. NeighborShed is a shared set of expectations for lending them to each other: how to offer, ask, hand over, return, and make it right when something goes wrong.

Sharing runs on trust, and trust runs on clear expectations

The scarce thing in a neighborhood is rarely the tool. It is the confidence that a loan will go well: that the drill comes back charged, that a late return gets a heads-up, and that a broken blade leads to a fair conversation instead of a feud.

When everyone knows the conventions, a yes gets easy. When the conventions are left unsaid, people stop lending.

A practice first, then software

The protocol works on paper, in a group chat, in a city equipment program, or inside an app. Each convention has a short, stable id such as NS-7, so a project can say exactly which ones it follows.

It is open and free to adopt. The aim is a pattern many apps and groups can share, so a neighbor who learns it once can lend anywhere.

The life of a share

Every loan moves through the same steps, whatever tool keeps track of it.

  1. 01 Offer

    Choose what you'll lend and who can see it. Describe its condition and how to care for it.

  2. 02 Ask

    Say what you need, how many, when, and what it's for.

  3. 03 Agree

    The lender decides each loan. No is a complete answer.

  4. 04 Hand over

    Meet somewhere you're both comfortable, and note the condition together.

  5. 05 Use and return

    Use it as agreed, speak up early if plans change, and bring it back as you found it.

  6. 06 Close

    Both sides confirm it's back. If something went wrong, make it right together.

Treat every tool with care. Communicate, return on time, and if you break it, work with the owner to make it right.

Built to be adopted

If you run a library of things, a tenants' association, a city loan program, or an app with a lending feature, you're invited to implement the protocol and list your project. Changes are proposed in the open, and the protocol improves as more groups use it.
